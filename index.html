Cara Upload ke GitHub Pages 🚀

Supaya website anniversary ini bisa diaksespacar kamu via link online gratis, ikuti langkah mudah berikut:

1. Struktur File Repository GitHub:

📁 my-anniversary/
├── 📄 index.html (File HTML ini)
├── 🎵 music.mp3 (Lagu latar)
├── 🎬 jj1.mp4 (Roblox First Meet)
└── 🎬 jj2.mp4 s/d jj10.mp4 (9 Video PDKT)

2. Upload ke GitHub:

  1. Buat Repository baru di GitHub (misal: happy-1st-anniversary).
  2. Upload file index.html, music.mp3, dan video jj1.mp4 s/d jj10.mp4.
  3. Klik menu Settings > Pages.
  4. Di bagian Branch, pilih main / master lalu Save.
  5. Tunggu 1-2 menit, link website siap dikirim ke pacar! ❤️
